# Aplikasi Catatan Sederhana (To-Do List) — Evolusi Perangkat Lunak

Aplikasi web berbasis Laravel yang menyediakan fitur Manajemen Catatan (CRUD Sederhana). Project ini dikembangkan sebagai bagian dari praktikum Evolusi Perangkat Lunak untuk mengimplementasikan alur kerja Git, Conventional Commits, branching strategy, serta CI/CD pipeline.

---

## 🚀 Fitur Utama

- **Create**: Menambahkan catatan/tugas baru beserta judul dan isinya.
- **Read**: Menampilkan daftar seluruh catatan yang tersimpan.
- **Delete**: Menghapus catatan yang sudah tidak diperlukan.

---

## 🛠️ Teknologi & Environment

- **Framework**: Laravel
- **Bahasa Pemrograman**: PHP
- **Database**: SQLite / MySQL
- **Version Control**: Git & GitHub
